# CoT Router — downloads

A Windows app that forwards Cursor-on-Target (CoT) traffic between ATAK/WinTAK mesh multicast, TCP and TAK Server (SSL/TLS), with TAK certificate enrollment from a QR code.

**[Download the latest version](https://github.com/malcolm-v-wood/cot-router-releases/releases/latest)** and pick `CotRouter-<version>-win-x64.exe`. It's a single file for 64-bit Windows 10/11 with nothing to install.

The exe isn't code-signed yet, so on first run SmartScreen says "Windows protected your PC". Click **More info → Run anyway**.
